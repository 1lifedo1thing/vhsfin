# Demo shelf sleeves

Made-up 1990s VHS sleeves for the open movies on the demo shelf (`--dart-define=VHSFIN_DEMO=true`), which is also what the store screenshots and website film show. These films never had VHS releases, and "VHSFin Home Video" is not a real label.

Each front cover and spine was generated with OpenAI's image generation (through Codex), using the film's own Blender artwork as the character reference. `tool/process_demo_sleeves.py` crops the spines and exports the WebP files in `assets/demo_sleeves/`.
